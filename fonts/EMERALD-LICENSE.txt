This file (emerald.woff2) is a MODIFIED version of that font and is distributed
under the same license (CC BY-SA 3.0). Modifications:
  - Glyph set reduced (subset) to the characters this game uses: ASCII/Latin-1,
    general punctuation, arrows, geometric shapes, miscellaneous symbols,
    CJK punctuation, Hangul syllables (U+AC00-D7A3) and Hangul jamo, full-width forms.
    Kerning ('kern') feature kept; hinting removed.
  - Converted from TrueType to WOFF2.
  - units-per-em changed from 1024 to 706 (glyph outlines and advance widths are
    unchanged, so glyphs render about 145% larger at the same CSS font-size) and
    the vertical metrics (ascender/descender/line gap) were reset, so that text
    keeps the size and baseline position of the previously used pixel font.
  - Font family name in CSS is 'PokemonEmeraldPro'.

Note on Hangul glyphs: the Hangul glyphs were not part of the original FontStruct
release; they were already included in the font file supplied to this project, which the
project owner confirmed as open source. Details of that source will be added here
when confirmed.
